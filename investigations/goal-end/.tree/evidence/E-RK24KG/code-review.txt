## Findings

### Finding 1: G-K0AXM0#4. An ended Goal's referred line still asks the owner to act, under LINES
After the end, `hyp status G` still prints `referred: the owner accepts or returns it` on the LINES row of a Goal line the runner referred. OWED and AWAITING OWNER are empty, as the line requires. But the line opens with "An ended Goal shows nothing that waits", and this row is still an item addressed to the owner. Its accept or return is now refused at write, so the owner cannot act on it.

Cause: `lineState`/`handWord` in internal/render/show.go do not check `p.Ended`. goalBlock in internal/render/status.go prunes FRONTIER and STALE for an ended Goal but not LINES.

This kind is at the edge of the line. Line 4's list after its colon names only OWED, AWAITING OWNER, the question waits and the GOALS row. If the builder reads it as uncovered, it is a reading at the stop. Test: TestReviewEndedGoalReferredLineStillAsksTheOwner (FAIL). Output on 0ebffbc:

### What I could not test
- **Line 7's ordering of a line against its end:** `citeEnd` decides whether a line came before or after an end by comparing the line's Goal-add id with the end's event id as strings (`l.Result < e.Event`). That is right for ULIDs in merge order. I did not build a merged log where a Goal added on another branch, citing a key of G settled before the end, gets an id that sorts after the end. Making that log needs hand-made ids, and I left it as a gap.
- **A live Goal whose premises point into an ended Goal:** a question of a live Goal can rest on a Hypothesis of an ended Goal through a depends_on premise. The ledger might then owe an item whose settling write is now refused. I did not build this case, and no Goal line places it.

package cli

// Review probes of the end of a Goal (G-K0AXM0). Each test states the Goal
// line it is a case of.

// G-K0AXM0#5: every write whose node leads to an ended Goal is refused with
// exit 1, naming the end. The builder's test covers the listed verbs; these
// are the other writes on a node of the Goal: abandon, reaffirm, amend,
// unselect, unlink, withdraw of an Experiment, and supersede from a node of
// the Goal.
func TestReviewOtherWritesUnderAnEndedGoalRefused(t *testing.T) {
	g, q, _ := endStore(t)
	h := must(t, "add", "hyp", "--parent", q, "--title", "H", "--why", "w")
	h2 := must(t, "add", "hyp", "--parent", q, "--title", "H2", "--why", "w")
	e := must(t, "add", "exp", "--parent", h, "--title", "E", "--recipe", "none", "--rubric", "reading", "--target", "none", "--why", "w")
	must(t, "link", h, "depends_on", h2, "--why", "w")
	qs := must(t, "add", "dq", "--parent", g, "--title", "QS", "--why", "ask")
	hs := supported(t, qs, "HS")
	must(t, "select", qs, hs, "--why", "w")
	must(t, "answer", "--end", g+"=outgrown", "--actor", "o")
	for _, args := range [][]string{
		{"abandon", h2, "--why", "w"},
		{"reaffirm", h, "--why", "w"},
		{"amend", h, "--body", "b", "--why", "w"},
		{"unselect", qs, "--why", "w"},
		{"unlink", h, "depends_on", h2, "--why", "w"},
		{"withdraw", e, "--why", "w"},
		{"supersede", h2, "--old", h, "--why", "w"},
	} {
		r := hyp(t, args...)
		if r.code != 1 || !strings.Contains(r.stderr, "is ended") || !strings.Contains(r.stderr, "outgrown") {
			t.Errorf("hyp %v under an ended Goal: exit %d, stderr %q; want exit 1 naming the end", args, r.code, r.stderr)
		}
	}
}

// G-K0AXM0#4: an ended Goal shows nothing that waits. A Goal line the
// runner referred to the owner is listed under LINES of hyp status; after
// the end it must not still say that the owner accepts or returns it.
func TestReviewEndedGoalReferredLineStillAsksTheOwner(t *testing.T) {
	g, q, keys := endStore(t, "one tenant per row")
	supported(t, q, "H")
	must(t, "checkpoint", "--goal", g, "--refers", keys[0]+"=no test bed", "--why", "w")
	before := hyp(t, "status", g).stdout
	if !strings.Contains(before, "referred: the owner accepts or returns it") {
		t.Fatalf("the store does not set up a referred line before the end:\n%s", before)
	}
	must(t, "answer", "--end", g+"=outgrown", "--actor", "o")
	st := hyp(t, "status", g).stdout
	if strings.Contains(st, "the owner accepts or returns it") {
		t.Fatalf("hyp status of an ended Goal still asks the owner to accept or return a line:\n%s", st)
	}
}

// G-K0AXM0#7 (its sentence "A line written before the end prints that its
// Goal has since ended", read as the line's own Goal): hyp show of a line of
// the ended Goal itself, written before the end, prints that the Goal has
// since ended.
func TestReviewOwnLineOfAnEndedGoalPrintsTheEnd(t *testing.T) {
	g, _, keys := endStore(t, "one tenant per row")
	must(t, "answer", "--end", g+"=outgrown", "--actor", "o")
	sh := hyp(t, "show", keys[0])
	want(t, sh, 0, "Line ")
	if !strings.Contains(sh.stdout, "ended") || !strings.Contains(sh.stdout, "outgrown") {
		t.Fatalf("hyp show of a line of the ended Goal does not say its Goal has since ended:\n%s", sh.stdout)
	}
}

// none: --end with a ref that resolves to a key, not a node, must exit with
// a usage or rule error and never panic.
func TestReviewEndOfAKeyIsAnError(t *testing.T) {
	g, _, keys := endStore(t, "one tenant per row")
	for _, ref := range []string{keys[0], g + "#9", "nosuch"} {
		r := hyp(t, "answer", "--end", ref+"=x", "--actor", "o")
		if r.code == 0 {
			t.Errorf("hyp answer --end %s=x: exit 0", ref)
		}
	}
	want(t, hyp(t, "status", g), 0, "— in_progress (")
}

// G-K0AXM0#1 with --as-of: hyp status at a point before the end reads the
// Goal in progress, and at the end reads it ended.
func TestReviewAsOfBeforeTheEnd(t *testing.T) {
	g, q, _ := endStore(t)
	want(t, hyp(t, "status", g, "--as-of", q), 0, "— in_progress (")
	r := hyp(t, "answer", "--end", g+"=outgrown", "--actor", "o")
	want(t, r, 0, " answer\n")
	want(t, hyp(t, "status", g, "--as-of", q), 0, "— in_progress (")
	end := strings.Fields(r.stdout)[0]
	want(t, hyp(t, "status", g, "--as-of", end), 0, "— ended (")
}

// G-K0AXM0#5, the replay half for an answer item: an answer of a reading of
// an ended Goal that a merged log holds after the end applies, and hyp
// check warns about it.
func TestReviewMergedAnswerAfterEndAppliesWithAWarning(t *testing.T) {
	g, q, _ := endStore(t)
	k := fullKey(t, openReading(t, q))
	rawEnd(t, "o", g, "outgrown", nil)
	late := rawEvent(t, "o", typeAnswer, "", map[string]any{"answers": []map[string]string{{"key": k, "text": "code only"}}}, "")
	r := hyp(t, "check")
	if strings.Contains(r.stdout, "rejected "+late) || !strings.Contains(r.stdout, "warn: "+late) {
		t.Fatalf("a merged answer under an ended Goal is not applied with a warning:\n%s", r.stdout)
	}
}
